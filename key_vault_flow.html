KeyVault C++ Implementation Flow

Visual diagrams showing the C++ implementation of TPM-protected key management.

1. Application Startup & Initialization

Phase: Application startup - harden process and initialize TPM connection.
Files: main() in key_vault_example.cpp, process_hardening.cpp, key_vault.cpp 
flowchart TD

2. Protecting a User Passphrase

Phase: User uploads encrypted PEM file and provides passphrase.
Method: KeyVault::protect(key_id, passphrase) 
sequenceDiagram
    autonumber
    participant User
    participant App as Application
    participant KV as KeyVault
    participant SSL as OpenSSL
(default provider)
    participant FS as Filesystem

    User->>App: Upload PEM + passphrase
    App->>KV: protect("user_key_A", passphrase)

    Note over KV: Create isolated OpenSSL context
(no TPM provider)

    KV->>KV: OSSL_LIB_CTX_new()
    KV->>SSL: OSSL_PROVIDER_load(ctx, "default")

    KV->>FS: fopen(pubkey_path)
    FS-->>KV: FILE*
    KV->>SSL: PEM_read_PUBKEY()
    SSL-->>KV: EVP_PKEY* (public key)

    Note over KV,SSL: RSA encrypt passphrase
with TPM public key

    KV->>SSL: EVP_PKEY_encrypt_init()
    KV->>SSL: EVP_PKEY_CTX_set_rsa_padding(PKCS1)
    KV->>SSL: EVP_PKEY_encrypt(passphrase)
    SSL-->>KV: encrypted_blob (256 bytes)

    KV->>KV: Cleanup contexts
    KV-->>App: ProtectedPassphrase{key_id, encrypted_blob}

    Note over App: Store in database

    App->>App: protected_pass.serialize()
    App->>FS: Store blob to DB

    Note over User,FS: Passphrase now protected
Original passphrase can be wiped

3. Using a Protected Key (Sign Operation)

Phase: Runtime - sign data using TPM-protected passphrase.
Method: KeyVault::sign_with_protected_key() 
sequenceDiagram
    autonumber
    participant App as Application
    participant KV as KeyVault
    participant TPM as TPM2 Chip
    participant SB as SecureBuffer
    participant SSL as OpenSSL

    App->>KV: sign_with_protected_key(protected_pass, pem_path, data)

    rect rgb(255, 240, 240)
        Note over KV,TPM: VULNERABLE WINDOW BEGINS

        KV->>KV: load_protected_key()

        Note over KV,TPM: Step 1: TPM decrypts passphrase

        KV->>TPM: EVP_PKEY_decrypt(encrypted_blob)
        TPM->>TPM: RSA decrypt inside silicon
        TPM-->>KV: plaintext passphrase

        KV->>SB: SecureBuffer(passphrase)
        Note over SB: Memory mlocked
Cannot be swapped

        Note over KV,SSL: Step 2: Load encrypted PEM

        KV->>SSL: PEM_read_PrivateKey(pem, passphrase)
        SSL->>SSL: AES-256-CBC decrypt PEM
        SSL-->>KV: EVP_PKEY* (user private key)

        Note over SB: Step 3: Wipe passphrase immediately

        KV->>SB: ~SecureBuffer()
        SB->>SB: volatile wipe loop
        SB->>SB: munlock()

        Note over KV,SSL: Step 4: Sign operation

        KV->>SSL: EVP_DigestSignInit(pkey)
        KV->>SSL: EVP_DigestSignUpdate(data)
        KV->>SSL: EVP_DigestSignFinal()
        SSL-->>KV: signature

        Note over KV,SSL: Step 5: Wipe key

        KV->>SSL: EVP_PKEY_free(pkey)

        Note over KV,TPM: VULNERABLE WINDOW ENDS
    end

    KV-->>App: signature

    Note over App: Only signature returned
No secrets in scope
Vulnerable Window: Between passphrase decryption and key wipe (~1-10ms). Mitigated by process hardening but not eliminated for user-provided keys.

5. C++ Class Structure

Overview: Main classes and their relationships. 
classDiagram
    class KeyVault {
        -Impl* impl_
        +KeyVault(tpm_handle, pubkey_path)
        +~KeyVault()
        +protect(key_id, passphrase) ProtectedPassphrase
        +load_protected_key(protected_pass, pem_path) EVP_PKEY*
        +sign_with_protected_key(protected_pass, pem_path, data) vector~uint8_t~
        +decrypt_with_protected_key(protected_pass, pem_path, ciphertext) vector~uint8_t~
    }

    class KeyVault_Impl {
        +uint32_t tpm_handle
        +string pubkey_path
        +OSSL_PROVIDER* tpm2_provider
        +OSSL_PROVIDER* default_provider
        +EVP_PKEY* tpm_key
        +init()
        +encrypt_passphrase(passphrase) vector~uint8_t~
        +decrypt_passphrase(encrypted) SecureBuffer
        +load_encrypted_pem(pem_path, passphrase) EVP_PKEY*
    }

    class SecureBuffer {
        -uint8_t* data_
        -size_t size_
        +SecureBuffer(size)
        +~SecureBuffer()
        +data() uint8_t*
        +size() size_t
        +wipe()
    }

    class ProtectedPassphrase {
        +string key_id
        +vector~uint8_t~ encrypted_data
        +serialize() vector~uint8_t~
        +deserialize(data)$ ProtectedPassphrase
    }

    class HardeningResult {
        +bool dumps_disabled
        +bool ptrace_disabled
        +bool memory_locked
        +string error_message
    }

    KeyVault *-- KeyVault_Impl : pimpl
    KeyVault_Impl ..> SecureBuffer : creates
    KeyVault ..> ProtectedPassphrase : uses
    KeyVault_Impl ..> EVP_PKEY : manages

    note for SecureBuffer "Memory is mlocked\nand securely wiped\non destruction"

    note for KeyVault_Impl "Holds TPM connection\nand OpenSSL providers"

7. Complete System Flow

End-to-end: From factory provisioning to runtime operation. 
flowchart TB
    subgraph FACTORY["Factory Provisioning (init.sh)"]
        F1[Run init.sh] --> F2[tpm2_createprimary]
        F2 --> F3[tpm2_create RSA key]
        F3 --> F4[tpm2_load]
        F4 --> F5[tpm2_evictcontrol 0x81010002]
        F5 --> F6[tpm2_readpublic → PEM]
    end

    subgraph UPLOAD["User Key Upload"]
        U1[User provides PEM + passphrase] --> U2[KeyVault::protect]
        U2 --> U3[Encrypt passphrase with TPM pubkey]
        U3 --> U4[Store encrypted blob in DB]
        U4 --> U5[Store encrypted PEM on disk]
    end

    subgraph RUNTIME["Runtime Operation"]
        R1[Application starts] --> R2[harden_process]
        R2 --> R3[KeyVault init]
        R3 --> R4[Load protected passphrase from DB]
        R4 --> R5[sign_with_protected_key]

        subgraph CRITICAL["Critical Section (~ms)"]
            R5 --> R6[TPM decrypts passphrase]
            R6 --> R7[Load PEM with passphrase]
            R7 --> R8[Wipe passphrase]
            R8 --> R9[Sign data]
            R9 --> R10[Free key]
        end

        R10 --> R11[Return signature]
    end

    FACTORY --> UPLOAD
    UPLOAD --> RUNTIME
